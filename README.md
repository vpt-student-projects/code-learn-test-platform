# Дипломный проект: Разработка системы онлайн-обучения и тестирования навыков программирования

## 1. Описание проекта

Skilllub — веб-платформа для онлайн-обучения программированию, позволяющая студентам изучать курсы, проходить тесты и выполнять практические задания с автоматической проверкой кода. Преподаватели могут создавать курсы и отслеживать прогресс, администраторы — управлять пользователями.

**Тип работы:** Выпускная квалификационная работа (дипломный проект)

## 2. Цель и задачи проекта

**Цель:** разработка веб-приложения для онлайн-обучения программированию с автоматической проверкой кода.

**Задачи:**
- анализ предметной области и обзор аналогов
- выбор и обоснование технологического стека
- проектирование архитектуры и базы данных
- реализация серверной и клиентской частей
- тестирование и развертывание

**Область применения:** онлайн-образование

## 3. Функциональность

- регистрация и аутентификация с ролевой моделью (студент, преподаватель, администратор)
- каталог курсов с поиском и фильтрацией
- иерархическая структура обучения (курсы → модули → уроки)
- тесты с автоматической оценкой
- практические задания с редактором кода
- автоматическая проверка кода через микросервис-компилятор
- отслеживание прогресса обучения
- сертификаты об успешном завершении курса
- панель преподавателя (создание курсов, управление контентом, просмотр прогресса)
- административная панель (управление пользователями, статистика)

**Ограничения:** поддержка языков Python и JavaScript (остальные — в перспективе)

## 4. Архитектура проекта

**Тип архитектуры:** многослойная (N-Layer) монолитная, клиент-сервер

**Технологии:**
- серверная часть: .NET 8, ASP.NET Core, C#
- база данных: Supabase (PostgreSQL)
- клиентская часть: HTML5, CSS3, нативный JavaScript
- аутентификация: JWT, BCrypt
- выполнение кода: микросервис на Python (FastAPI), Docker
- веб-сервер: Nginx
- система контроля версий: Git, GitHub

**Структура проекта:**
- `backend/` — серверная часть (ASP.NET Core)
- `frontend/` — клиентская часть (SPA на JavaScript)
- `compiler/` — микросервис-компилятор (FastAPI, Docker)
- `tests/` — модульные тесты (xUnit)

## 5. Установка и запуск

**Требования:**
- .NET 8 SDK
- Node.js (для Monaco Editor)
- Docker (для компилятора)
- Git

**Установка:**

```bash
git clone https://github.com/vpt-student-projects/code-learn-test-platform.git
cd code-learn-test-platform
Запуск серверной части:

bash
cd backend
dotnet restore
dotnet run
Запуск компилятора:

bash
cd compiler
docker build -t code-executor .
docker run -p 8000:8000 code-executor
Запуск клиентской части:
Открыть frontend/index.html в браузере или использовать Live Server.
